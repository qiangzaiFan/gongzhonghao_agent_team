# AIGC 强制门禁

## 适用范围

`tizhi_content/articles/` 下每一篇新生成或修改后的文章，都必须运行本地中文 AIGC 检测。

## 固定门槛

- `human >= 90%`
- `ai <= 10%`
- 检测报告中的 `article_sha256` 必须与当前文章一致。

只有同时满足三项，才能对外标记为“AIGC 检测通过”。

## 标准命令

```bash
.venv/bin/python tizhi_content/ai_detector.py \
  tizhi_content/articles/<article>.md
```

默认报告保存到 `tizhi_content/reviews/auto/<article>.json`。

## 强制顺序

1. 完成标题和正文。
2. 完成人工可读性、原创度、事实和风险复核。
3. 运行 AIGC 检测。
4. 未通过时，只修改报告标记的片段，然后重新检测。
5. 任何文字修改都会使旧报告失效，必须重新运行。
6. 最多进行3轮针对性修改；仍未通过时，保留失败报告并标记“待人工复核”。

## 编辑原则

- 优先删除空泛过渡、连续对仗、排比和无来源的漂亮话。
- 优先补充“我”“我们办公室”的具体行为和生活反应。
- 不为了过检编造亲历、政策、人事消息或可识别单位事实。
- 不为了过检故意制造错别字、语病或破坏文章逻辑。
- AIGC 结果只是编辑风险信号，不是作者身份证明。
