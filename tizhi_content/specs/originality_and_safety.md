# 原创与发布安全规则

## 参考文章的使用范围

可以提炼：选题领域、标题类型、开篇方式、分段节奏、论证路径、情绪承诺和词汇层级。

不得复用：独特句子、段落、比喻、金句、私人经历、特定案例和观点顺序。

标题可使用相同选题、通用句式，或按用户指定使用原题。标题重复不放宽正文原创要求。

## 新稿必须同时满足

- 主要论点与参考文章不同。
- 所有场景、案例和表达重新构思。
- 论证顺序不跟随单篇参考文章。
- 文章脱离参考原文仍能独立成立。
- 读者不会被误导为原博主本人所写。

## 敏感主题

涉及纪检、人事任免、酒局、礼品礼金、公款、婚姻和具名部门时：

- 使用“可能”“通常”“在一些地方”等审慎描述。
- 不断言真实个人或单位的私密事实。
- 不编造政策条文、数据或内部文件。
- 只提供一般风险认知，不教人规避监管或钻漏洞。

## 成稿自检

- [ ] 如果标题重复，已确认是用户指定或通用表达
- [ ] 无连续句式或段落级改写
- [ ] 主论点、案例和结构均为新构思
- [ ] 事实性内容有依据，观察与事实已区分
- [ ] 未指控可识别的个人或单位
- [ ] 发布或进入草稿箱前已使用 `wenyan-mcp` 的 `lapis` 主题优化排版，呈现清爽政务蓝 / 商务简约风，适合手机长文阅读
- [ ] 公众号文章作者为“田间里的烟火”
- [ ] 敏感主题已标记人工复核
- [ ] AIGC 报告与当前文章哈希一致，且 `human >= 90%`、`ai <= 10%`
