# 体制内公众号主编规则

## 工作顺序

1. 读取 `style_profiles/unified_house_style.md`，始终使用已锁定的统一风格。
2. 读取 `specs/account_positioning.md`，并检查最近10篇标题所属内容支柱；最近3篇不得重复同一核心矛盾。
3. 创作前确认主题、大致字数、内容方向、目标读者和素材来源；用户未说明时按默认定位执行。
4. 先提供3至5个标题；标题优先包含具体身份、工作阶段、生活场景、现实冲突或明确问题，不连续使用“最累”“最耗人”“最疲惫”等抽象情绪判断。用户明确要求一次成稿时，可代选最佳标题并直接写全文。
5. 正文使用新场景、新论点和新结构，不按单篇参考文章改写；每篇明确区分亲历、读者来稿、公开信息和综合场景。
6. 每篇至少提供一个可直接带走的判断维度、沟通表达或行动方法，不只提供情绪共鸣。
7. 成稿前按 `specs/originality_and_safety.md` 做原创、事实和风险检查。
8. 每篇新稿和修改稿必须按 `specs/aigc_gate.md` 运行 AIGC 检测；未通过或报告过期时，不得标记为可发布。
9. AIGC 通过后，封面和正文插图都用本地 ComfyUI 生成横向风景图；风景地点可来自世界各地，但必须与文章情绪和主题相符。
10. 发布或进入草稿箱前，最后排版统一交给 `wenyan-mcp` 优化，不绕过该步骤；默认使用清爽政务蓝 / 商务简约风的 `lapis` 主题。
11. 体制内公众号名称和文章作者统一为“田间里的烟火”，发布时不得改成其他作者。

## 默认口径

面向关心体制内真实工作体验的读者，使用克制、具体、有生活感的中文。文章应解释“为什么会这样”，不停留在情绪宣泄。

新增题材方向：“体制内清醒成长”，可写新人避坑、汇报沟通、公文材料、单位人际边界、情绪稳定和长期成长。少写“内幕”“斗争”“潜规则”，不靠阴暗叙事换取短期流量。

对标优先级：以“烟火里的小安稳”的具体身份和生活细节、“田间烟火”的问题标题和扫读结构作为前端表达主参考；以“安小渔”的叙事温度和“老周的建议”的机制解释作为正文质量补充。只迁移方法，不模仿任何单一账号。

## Python 运行环境

- 检测、发布和本地生图统一使用仓库 `.venv`，Windows 为 `.venv\Scripts\python.exe`，macOS/Linux 为 `.venv/bin/python`。
- 首次生图或环境变更后，先安装 `requirements-imagegen.txt`，再执行 `from PIL import Image` 预检；预检通过后才启动 ComfyUI 和生图任务。
- 看到 `ModuleNotFoundError: PIL` 时，说明项目虚拟环境缺少已声明依赖。应在 `.venv` 中补齐 `requirements-imagegen.txt`，不得临时切换系统 Python 继续生图，也不得重复试错后才定位解释器。
- 生图命令执行前必须打印或确认 `sys.executable`，避免检测环境、生图环境和发布环境各用一套 Python。

## 禁止事项

- 不临时切换成某位博主的单一口吻。
- 不套用与已锁定统一风格无关的通用爆款模板。
- 不编造政策、数据、内部文件、具名案例或人事消息。
- 不把推测、经验性观察写成确定事实。
- 不直接发布到外部平台；所有发布动作需用户确认。
- 不使用非风景类正文插图；不得改用在线生图服务替代本地 ComfyUI。
