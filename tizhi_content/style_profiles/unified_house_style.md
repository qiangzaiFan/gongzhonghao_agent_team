# 统一写作语感

- 状态：已锁定
- 锁定日期：2026-07-31
- 适用账号：体制内县域职场观察号
- 参考范围：安小渔、烟火里的小安稳、田间烟火、老周的建议的可迁移方法
- 对标优先级：烟火里的小安稳、田间烟火为主；安小渔、老周的建议为辅

## 标题语感

新增题材方向可写“体制内清醒成长”：新人避坑、汇报沟通、公文材料、单位人际边界、情绪稳定和长期成长。可以写现实，但不写成“内幕”“斗争”“潜规则”口吻。

### 长度

- 常规文章：18至30字。
- 来信或强场景文章：30至45字，最多交代身份、场景和核心冲突。
- 短标题只用于强情绪或强叙事，不为了短而模糊。

### 常用结构

1. 现象提问：具体身份或岗位 + 可见变化 + 为什么。
2. 场景反差：外人理解的好处 + 身在其中的代价。
3. 个人记录：年龄/工龄/家庭身份 + 一件小事 + 真实变化。
4. 问题说透：一个读者真在犹豫的选择 + 文章给出的判断维度。

标题至少呈现以下信息中的两项：具体身份或岗位、年龄或工作阶段、可见场景、现实冲突、明确问题或选择。只有“最累”“最耗人”“最疲惫”“别委屈自己”等抽象判断而没有具体对象的标题，不作为首选。

备选标题中至少包含一个疑问型标题和一个具体场景型标题。疑问必须对应正文真正回答的问题，不使用伪问题制造悬念。

### 用词与标点

- 优先使用“会议”“表格”“群消息”“值班表”“工资条”“孩子放学”等具体名词。
- 可使用“说到底”“更现实的是”“外人看见的是”等口语过渡，每篇不超过2次。
- 少用叹号，不连续使用疑问号，不在标题中堆叠引号。
- 不用“真相来了”“答案比想象中现实”“一定要看”等可替换的流量套话。

### 重复规则

- 创作前检查最近10篇标题和核心论点；最近3篇不得重复同一核心矛盾。
- 允许同题和通用句式，但新稿必须更换目标读者、现实冲突和最终判断，不能只更换人物或场景。
- 用户指定原题时可使用原题，但新文必须重新确定论点、结构、场景和例子。
- 未指定时，对带有个人经历或强识别度的长标题主动重写。
- 不复用既有文章的完整段落、机制拆解和建议顺序。

## 作者口吻

- 主体口吻：“我看到一件小事，想把它背后的逻辑说清楚”。
- 优先写“我”和“我们办公室”的具体行为，例如打电话、收包、热饭、等群消息；亲历动作比泛化的“有人”更有可信度。
- 不站在高处教人，不把自己包装成掌握内幕的人。
- 叙事用“我”，共情用“我们”，只在提问或建议时用“你”。
- 先承认人的难处，再分析规则和选择；不轻易归因为个人不努力。
- 人物和故事必须标明可信来源：亲历写清“我”或“我们办公室”，读者来稿明确说明，无法对应单一真实事件时标记为综合场景；不把通用案例包装成具名亲历。

## 句式与段落

- 常规句子18至32字；转折或收束可使用8至15字短句。
- 连续三句不使用同一个开头，避免“首先/其次/最后”的机械排列。
- 每段1至3句，通常30至70字；关键判断可单独成段。
- 每个小节只讲一层逻辑，小节之间留一个空行。
- 默认正文1400至1800字；生活短记可以800至1200字，深度机制文可以1800至2200字。

## 开篇写法

开篇80至150字，第3段前让读者知道文章要说什么。按优先级使用：

1. 具体场景：一条消息、一张值班表、一次散会、一顿晚饭或一次临时电话。
2. 反差观察：别人看见的稳定，与当事人承担的具体成本。
3. 真问题：读者正在犹豫的事，不用自问自答的假钩子。

禁止用空泛时代背景、“最近很多人问我”或长篇自我介绍开头。

## 行文逻辑

默认结构是：

1. 场景：让问题看得见。
2. 冲突：点出事情的真正别扭之处。
3. 机制：用2至3层原因解释这种现象怎样形成。
4. 人的体感：回到当事人的家庭、情绪和现实选择。
5. 带走的判断：给出边界、认知或小幅可执行的调整。

只在内容确实有独立层次时使用3个小标题或 `01/02/03`。生活叙事不强行分点。

## 金句风格

- 每篇1至3句，必须从上文的具体冲突中长出来。
- 常用功能：把表面好处与隐性代价放在一句话里，或把个人委屈还原为结构性压力。
- 用具体名词和动词，不写“人生就是一场修行”类空心句。
- 不引用或改写参考文章金句，不为了截图而硬写对仗句。

## 结尾与互动

- 先用2至4段收回开篇场景，再给出一个克制判断。
- 最后可用1句真实问题互动，例如询问读者遇到的具体做法或感受。
- 不在正文中堆叠“点赞+在看+转发+关注”，不用空泛祝福收尾。

## 表情与排版

- 机制分析、人事、纪律和政策文：不使用 emoji。
- 家庭日常和生活短记：全文最多1个 emoji，只放在结尾互动处。
- 标题默认不使用 emoji。
- 小标题最多3个，不使用多层嵌套，不连续加粗整段。

## 成稿验收

- 第3段前已出现主题和核心冲突。
- 至少有1个可见的工作或生活场景。
- 至少解释1层单位运行逻辑，不只是吐槽。
- 没有冒充内部人士、编造制度或承诺人事结果。
- 不保留任何参考文章的句子、案例和论证顺序。
- 删掉标题和作者名，正文仍能呈现稳定的本账号语感。
