# 暖暖小厨类文章风格拆解

本文用于抽象学习，不用于复制原文。核心不是“同一句话怎么说”，而是“为什么这类家常饭内容容易被读者点开并读完”。

## 账号底层吸引力

1. **饭很普通**：早餐、午餐、晚餐、一人食、夫妻二人、孩子餐，都是读者家里会出现的场景。
2. **信息很具体**：花多少钱、几个人吃、多少分钟、几道菜、用什么食材，标题和正文都有数字锚点。
3. **生活理由明确**：天热、下雨、送孩子、下班、清冰箱、想省钱、孩子想吃、老公带饭。
4. **做法可复现**：不是只晒成品，会写到切法、焯水、调味、火候和失败规避。
5. **不完美但可信**：卖相一般、食材买老了、做多了、家人意见不一，这些细节让文章像真人日常。

## 常见选题类型

- `日常晒餐`：晒晒一家三口的晚餐，两菜一汤，荤素搭配。
- `一人食`：一个人的午餐，低成本、比外卖舒服、简单不糊弄。
- `早餐合集`：20-30 分钟搞定 3-5 样，粗细搭配。
- `孩子餐`：孩子晚餐、宵夜、恢复期饭菜、爱吃的面/饭。
- `夫妻二人`：夫妻午餐、老公工作餐、两个人不同口味。
- `河南家常`：捞面条、烩面、蒸菜莽、烧饼、面筋汤、发面饼。
- `面食主食`：包子、花卷、馒头、蒸饺、肉盒子、软饼。
- `省钱饭菜`：5 元、10 元、15 元、清冰箱、菜市场顺手买。
- `外食复盘`：偷懒不做饭，花了多少钱，值不值。

## 标题公式

主公式：

```text
晒晒 + 人数/身份 + 餐次 + 数字锚点 + 菜品/搭配 + 结果
```

可替换字段：

- 人数/身份：一家三口、两个人、夫妻二人、一个人、孩子、老公、河南人。
- 餐次：早餐、午餐、晚餐、早午餐、工作餐、宵夜。
- 数字锚点：15 分钟、30 分钟、11 元、两菜一汤、4 样、5 天不重样。
- 结果：比外卖强、清爽无负担、孩子爱吃、下饭、省心、网友却说。

标题要避免一味夸张。读者点开的理由是“这顿饭我也能做”，不是“震惊全网”。

## 正文节奏

1. 开头先说今天的生活场景。
2. 接着晒整餐：几个人吃、几道菜、花费和整体感受。
3. 省钱或日常晒餐常补一段食材明细：哪样多少钱、哪样用了半份，金额要像真实菜市场账。
4. 再按菜品拆步骤：食材准备、关键做法、火候判断。
5. 中间穿插个人偏好：少油、不想油炸、孩子爱吃、老公喜欢、河南口味。
6. 结尾写吃后感或互动：饱没饱、下次怎么改、大家爱不爱这种搭配。

## 图片节奏

- 暖暖小厨类文章很少把图片连续堆在一起，主节奏是“一张图 -> 一句说明/步骤 -> 下一张图”。
- 两张图片之间通常至少有一句状态说明、做法补充、步骤编号或菜品标题。
- 可以偶尔连续放 2 张图，但只能作为成品对比或局部细节，不能成为常规排版。
- 生成草稿时默认禁止连续图片，方便后续补真实实拍图。
- 普通晒餐建议 16-20 张图；复杂面食或多步骤主菜建议 18-22 张图。
- 主菜尽量有 `【食材准备】` 和 8-10 个步骤编号，配菜/汤水各 2-3 步。

## 语言特征

- 句子不追求漂亮，追求顺口和像人说话。
- 常用词：简单、快手、家常、清淡、下饭、热乎、省事、舒服、营养不将就。
- 可出现少量口语：真香、真得劲、吃美了、看着凑合、谁吃谁迷糊。
- 多写动作和判断，少写宏大感悟。
- 互动轻，不强行升华。

## 原创保护

- 标题不能与知识库任一标题完全相同。
- 不连续复用同一开头，例如每篇都写“送完孩子我顺路去菜市场”。
- 不复刻原文菜品组合和步骤顺序。
- 图片必须来自自有实拍、授权图库或后续自建图池。
- 写手只能学习结构、节奏和表达密度，不能复制可识别文本。

## 相似度目标

- 推荐目标：风格像 80%-85%，文本重合低于 10%。
- 可以相似的部分：标题公式、人数/餐次/金额钩子、先晒饭再拆做法、家常碎念、步骤图密度、吃后互动。
- 必须不同的部分：具体标题、菜品组合、开头场景、做法表述顺序、原作者口头禅、图片和署名。
- 如果一篇读起来已经像“同一个作者换词”，要降相似度；如果只像普通菜谱教程，要提高生活场景和晒餐感。
