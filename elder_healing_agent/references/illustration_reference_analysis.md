# 悦漫先生参考插图拆解

## 一句话判断

用户要的不是普通正文配图，而是“水彩漫画 + 金句大字 + 纸纹底 + 红章署名感”的公众号情绪卡。它本身就是内容的一部分，有收藏和转发属性。

## 画面结构

1. 画布比例：基本为 1:1 正方形，适合公众号正文和社群转发。
2. 背景：满版米白粗纸纹，像宣纸或手工纸，不是纯白，也不是渐变背景。
3. 主体位置：主体多在上半部或中上部，留出下半部给大字。
4. 字体区域：下方 25%-40% 是大号毛笔字，深灰/黑色，常为 1-2 行。
5. 品牌区：右下角有红色小印章和小署名，形成稳定识别。

## 插画主体

常见主体不是抽象风景，而是一个清楚的生活/情绪场景：

- 生病：动物躺在病床上，冰袋、输液、药瓶、床被等物件齐全。
- 钱：动物抱着铜钱、钞票、金币，表情有一点幽默。
- 时间：沙漏、花枝、落叶，表达身体和余生。
- 关系：两个人看星空、手机、饭桌、门口钥匙等。

主体必须“可读”：读者不用看正文，也能大概知道这张图在讲什么。

## 质感要求

- 线条：黑色手绘线稿，有自然粗细变化。
- 上色：水彩淡彩，边缘有晕染和纸面吸水感。
- 阴影：柔和，不做 3D 塑料感。
- 细节：物件要完整，不能只有一个符号。
- 情绪：温柔、幽默、清醒，不恐怖、不卖惨、不幼稚。

## 文字要求

参考图的文字不是小 caption，而是主视觉：

- 字要大，要厚，要像毛笔/手写。
- 内容短，通常 8-18 个字，最多两行。
- 文字必须和文章核心判断绑定。
- 不能有乱码、错字、多字、少字。

建议生产方式：

1. 出图模型生成“无字主体图 + 纸纹背景 + 底部留白”。
2. 后期叠加准确中文毛笔字。
3. 右下角叠加“晴川黄鹤”自有红章/署名。

这样比直接让模型生成中文更稳定。

## 晴川黄鹤改造方向

可以学：

- 纸纹、水彩、漫画、金句卡结构。
- 图文强绑定。
- 温柔幽默但有生活判断。
- 固定右下角品牌识别。

不能学：

- 悦漫先生原图。
- Yue Man 字样。
- 原红章和签名。
- 可识别的具体构图、角色和图中文字。

晴川黄鹤应建立自己的固定符号：

- 淡金色小鹤或温柔拟人动物。
- 米白纸纹。
- 深灰大字。
- 自有红章“晴”或“晴川”。
- 小署名“晴川黄鹤”。

## 验收标准

一张图达到可用，必须同时满足：

- 1:1 正方形。
- 米白纸纹明显。
- 主体是水彩漫画，不是扁平矢量图。
- 主体与文章段落高度对应。
- 下方有准确大字金句，或明确预留了后期大字区域。
- 右下角是自有品牌标识，不含 Yue Man。
- 无乱码、无水印、无搬运痕迹。
- 看起来像公众号可收藏插画卡，而不是临时占位图。
