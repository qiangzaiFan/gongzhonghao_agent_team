# 标题系统

## 标题原则

- 一眼让 50 岁以后的人觉得“这说的是我”。
- 标题可以清醒、有刺痛感，但不要诅咒、恐吓和攻击。
- 每个标题最好包含至少一个具体入口：年龄、身体、钱、子女、关系、病、睡眠、退休。
- 不复用参考博主原题，不连续使用同一外壳。

## 常用公式

1. 年龄 + 劝停：`50 岁以后，别再把心神放在不值得的人身上`
2. 晚年 + 反差：`人老了，最怕的不是没钱，是这件事`
3. 身体 + 提醒：`突然生病后才明白，身体早就在提醒你`
4. 子女 + 边界：`老了以后，和子女最好的关系，是有边界`
5. 钱 + 底气：`晚年最大的底气，不是面子，是手里的钱`
6. 情绪 + 伤身：`真正拖垮你的，不是年纪，是长期憋着的情绪`
7. 关系 + 断舍离：`有些关系，越早看淡，晚年越好过`
8. 动作 + 疗愈：`睡前少想这几件事，身体会轻一点`

1. 有些关系，越早看淡，晚年越好过

3. 人老了，能独处是一种福气

5. 晚年最好的活法，是少期待
6. 不热闹的日子，也可以过得很安稳
7. 自己能照顾自己，就是最后的体面

10. 晚年慢慢好，从少操心开始

## 标题轮换规则

- 连续 3 篇不能都以“人老了”开头。
- 连续 3 篇不能都写子女。
- 每 7 篇至少 2 篇身体情绪，1 篇钱，1 篇独处。
- 医疗相关标题每周不超过 2 篇，避免账号过度焦虑化。
- 强冲突标题后面要接一篇温柔型文章，保持账号有光。
